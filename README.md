# techseo

Claude skills for technical SEO work.

| Skill | What it does |
|---|---|
| [sitemap-builder](sitemap-builder/) | Builds or refreshes the sitemap of any site, yours or a competitor's. Reads the live XML sitemap (or crawls, or uses the Internet Archive), audits every URL, optionally adds Search Console clicks, and writes a clean `sitemap.xml` plus an interactive site-map page. |

## Install

Copy a skill folder into `~/.claude/skills/` (for example `sitemap-builder/`), or zip the folder as a `.skill` file and add it in Claude. The scripts use only the Python 3 standard library.
